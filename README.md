# Vasim Portfolio

Personal portfolio website of **Mohd. Vasim Shah**, a BCA student from Varanasi who is interested in software and game development.

**Live site:** https://vasim-shah21.github.io/VasimPortfolio/

## About

This is a single-page portfolio built with plain HTML, CSS and JavaScript. It has no frameworks, no build step and no dependencies, so it runs anywhere a browser does.

## Features

- Clean, responsive layout for mobile, tablet and desktop
- Lightning blue and silver white theme with a light/dark mode toggle
- Sections for About, Technical Skills, Project, Education and Certifications, and Contact
- SkillForge shown as a quest log of completed and upcoming phases
- Smooth scrolling and keyboard-friendly navigation
- Respects the visitor's reduced-motion setting

## Tech stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript
- Google Fonts: Bricolage Grotesque and DM Sans

## Run locally

1. Clone the repository:
```bash
   git clone https://github.com/vasim-shah21/VasimPortfolio.git
```
2. Open `index.html` in your browser. You can also use the Live Server extension in VS Code.

## Deploy on GitHub Pages

1. Push `index.html` to the `main` branch of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live in a minute or two.

## Customize

- **Colours:** edit the CSS variables at the top of the `<style>` block in `index.html`.
- **Content:** edit the text inside each `<section>`.
- **Links:** update the GitHub, LinkedIn and email links in the Contact section.
